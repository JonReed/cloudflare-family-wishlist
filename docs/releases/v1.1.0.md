# Family Wishlist v1.1.0

A smoother everyday wishlist: faster shared-link drafts, clearer gift controls and more compact
layouts, with a new [family user guide](../USER_GUIDE.md). This is a backwards-compatible minor
release, prepared on 24 September 2026.

## What's changed

- Shared product links open a draft immediately while product details load in the background.
  A fetching panel protects fields that will receive those details; notes, priority and list choices
  remain editable. **Enter details myself** lets you continue without waiting or being overwritten
  by a late result. Manual lookup and no-JavaScript forms remain available.
- Edit and remove controls use reusable dialogs with confirmation, unsaved-edit protection and
  keyboard focus handling. A compact **Edit this wish** menu keeps maintenance separate from buying
  controls, with inline forms when JavaScript is unavailable.
- Gift status and actions are easier to distinguish from editing. **Mark as not bought** reverses a
  purchase status without releasing the reservation; **Cancel claim** is a separate action.
- Smaller family gift tags fit three across on phone layouts. **My wishlist** identifies your list;
  shorter navigation, a combined wish-count/share row and compact item actions reclaim space.
- Shop links stand out, sharing and menu underlines are consistent, and family invitation forms
  give clearer pending and completion feedback.

## Upgrading from v1.0.0

No new database migrations, installation settings or secrets are required by this release. There
are no intentional breaking changes. Follow the normal [backup and upgrade procedure](../BACKUP_RESTORE_UPGRADE.md)
and [release-channel guidance](../RELEASES.md); publishing a release does not update every independent
installation. Fork owners remain responsible for synchronising their code and checking deployment.

The optional version-pin updater remains experimental. Genuine scheduled delivery and the stricter
independent fresh-account acceptance run remain outstanding; see
[automatic updates](../INSTALLATION_UPDATES.md). No installer-protocol change is included here.

## Security and verification

The release's application changes received a Codex Security diff scan and an independent OpenAI
Daybreak Blue review, with no concrete plausible vulnerabilities found in the reviewed range.
The [security review record](../SECURITY_REVIEW.md#v110-release-diff-review) gives the exact commits,
checks and limitations. Release preparation after that range changes documentation and package
version metadata only; it does not add application behaviour or dependency updates.

The release workflow reruns the quality and dependency-audit gates before promoting the exact tagged
commit to `stable`. Consult the [published release](https://github.com/JonReed/cloudflare-family-wishlist/releases/tag/v1.1.0)
and **Release to stable** workflow for publication and promotion results. Source review is not an
independent certification or a live audit of a household's Cloudflare configuration.

Privacy is unchanged: all admitted family members can edit every list, while the list owner never
receives its gift claims or purchase status. Public viewing links remain read-only and omit claims.
