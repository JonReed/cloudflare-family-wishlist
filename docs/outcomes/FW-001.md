## Intended experience

Open a shared wishlist, choose a gift and record that it has been bought without
creating an account. Other gift givers should be able to avoid buying it again.
The guest should be able to recover their reservations and correct a mistake.

## Where things stand

The implementation and automated test definitions already exist. Jon reported on
11 October 2026 that he has not yet tested this feature or given it a QA pass.
This outcome therefore remains **Not done — awaiting QA**.

The criteria above are proposed for that review. Source files show what has been
implemented and what tests are defined; they do not establish that the experience
works end to end or that Jon has accepted it.

## Existing privacy boundary

Other guests see a reservation, not the buyer's identity or bought status.
Signed-in recipients must not receive their own gift's reservation details.
An anonymous visitor with the sharing link can see availability, including if they
are the recipient; this is an existing sharing trade-off, not a new guarantee.
